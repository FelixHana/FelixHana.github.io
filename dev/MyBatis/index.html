    入门¶

    • MyBatis & MySQL 依赖
    • 实体类及相关方法
    • 配置数据库连接 application.properties
    • 持久层接口 Mapper
      • @Mapper 表示是 mybatis 中的 Mapper 接口，框架会自动生成接口的实现类对象(代理对象)，并给交 Spring IOC 容器管理
      • @Select 代表 select 查询
        @Mapper
public interface UserMapper {
    @Select("select id, name, age, gender, phone from user")
    public List<User> list();
}
    • 单元测试
      • 测试类在运行时，会自动通过引导类加载Spring的环境（IOC容器）
      • 通过 @Autowired 将 bean 注入SpringBoot
    • 数据库连接池
      • Container 负责分配、管理数据库连接
      • 允许应用程序重复使用一个现有的数据库连接
      • 释放空闲时间超过最大空闲时间的连接
      • 好处：资源重用/提升响应速度/避免连接遗漏

    lombok¶

    • 通过简单的注解来简化和消除一些必须有但很臃肿的代码
    注解 作用
    @Getter/@Setter 为所有的属性提供get/set方法
    @ToString 会给类自动生成易阅读的 toString 方法
    @EqualsAndHashCode 根据类所拥有的非静态字段自动重写 equals 方法和 hashCode 方法
    @Data 提供了更综合的生成代码功能（@Getter + @Setter + @ToString + @EqualsAndHashCode）
    @NoArgsConstructor 为实体类生成无参的构造器方法
    @AllArgsConstructor 为实体类生成除了static修饰的字段之外带有各参数的构造器方法。

    XML 映射文件¶

    开发规范¶

    1. XML 映射文件的名称与 Mapper 接口名称一致，并且将 XML 映射文件和 Mapper 接口放置在相同包下（同包同名）
    2. XML 映射文件的 namespace 属性为 Mapper 接口全限定名一致
    3. XML 映射文件中 sql 语句的 id 与 Mapper 接口中的方法名一致，并保持返回类型一致。
    4. dtd 约束
      <?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
  PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
  "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.zcy.mapper.Empmapper">

</mapper>

    if & where 实现复合条件¶

    <if test="cond">
   要拼接的sql语句
</if>
    • <if>用于判断条件是否成立。使用test属性进行条件判断，如果条件为true，则拼接SQL
    • <where>只会在子元素有内容的情况下才插入where子句，而且会自动去除子句的开头的AND或OR
    <select id="list" resultType="com.itheima.pojo.Emp">
        select * from emp
        <where>
             <!-- if做为where标签的子元素 -->
             <if test="name != null">
                 and name like concat('%',#{name},'%')
             </if>
             <if test="gender != null">
                 and gender = #{gender}
             </if>
             <if test="begin != null and end != null">
                 and entrydate between #{begin} and #{end}
             </if>
        </where>
        order by update_time desc
</select>

    update & set 动态更新¶

    • 如果更新时传递了值才更新
    • <set> 动态的在SQL语句中插入set关键字，并会删掉额外的逗号
    <!--更新操作-->
    <update id="update">
        update emp
        <!-- 使用set标签，代替update语句中的set关键字 -->
        <set>
            <if test="username != null">
                username=#{username},
            </if>
            <if test="name != null">
                name=#{name},
            </if>
            <if test="gender != null">
                gender=#{gender},
            </if>
            <if test="image != null">
                image=#{image},
            </if>
            <if test="job != null">
                job=#{job},
            </if>
            <if test="entrydate != null">
                entrydate=#{entrydate},
            </if>
            <if test="deptId != null">
                dept_id=#{deptId},
            </if>
            <if test="updateTime != null">
                update_time=#{updateTime}
            </if>
        </set>
        where id=#{id}
    </update>
