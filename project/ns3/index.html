    NS-3 DCQCN¶

    What's DCQCN?¶

    • RoCEv2
      RoCEv2 stands for "RDMA over Converged Ethernet version 2." It is a network protocol that allows Remote Direct Memory Access (RDMA) operations to be performed over Ethernet networks. RDMA enables data to be transferred directly into or out of the memory of one computer into another, without involving the operating system or CPU, which can significantly improve data transfer speeds and reduce latency.
      RoCEv2 supports PFC, which allows certain types of traffic, such as RoCE traffic, to be prioritized over other types of traffic on the network, ensuring that RDMA traffic gets the necessary bandwidth and is not delayed by other traffic.
    • DCQCN(Data Center Quality of Service Congestion Notification)
      It is a congestion control mechanism used in data center networks to manage and alleviate congestion. DCQCN is specifically designed for use with RDMA technologies like RoCE

    ECMP¶

    About ECMP
Equal-cost multi-path routing (ECMP) is a _routing strategy_ where packet forwarding to a single destination can occur over `multiple best paths` with `equal routing priority`. 
Multi-path routing can be used in conjunction with most routing protocols because it is a `per-hop local decision` made independently at each router. It can substantially increase bandwidth by load-balancing traffic over multiple paths
It is commonly used on Layer 3.

    To avoid reordering and retransmitting, routers and switches work hard to make sure that all packets that belong to the same TCP session (or UDP flow) are transmitted over the same link.
    - Load balancing based on:
    MAC - all the traffic between two routers is transmitted over the same link
    3-tuple - (protocol, src, dst) better than MAC
    5-tuple - (protocol, src, dst, src_port, dst_port) best way to perform ECMP
    Equal-Cost Multi-Path Routing (ECMP) (youtube.com)
    - 4 options: IP-modulo, IP-hash(with seed), Round-Robin, Weighted R-R

    uint32_t
Ipv4GlobalRouting::GetTupleValue (const Ipv4Header &header, Ptr<const Packet> ipPayload)
{
    // We do not care if this value rolls over
    uint32_t tupleValue = (header.GetSource ().Get ()*59) ^ header.GetDestination ().Get () ^ header.GetProtocol ();
    switch (header.GetProtocol ())
    {
        case UDP_PROT_NUMBER:
            {
                UdpHeader udpHeader;
                Ptr<Packet> p = ipPayload->Copy();
                p->RemoveHeader(udpHeader);
                SeqTsHeader seqh;
                p->RemoveHeader(seqh);
                //ipPayload->PeekHeader (udpHeader);
                NS_LOG_DEBUG ("Found UDP proto and header: " << 
                    udpHeader.GetSourcePort () << ":" <<  
                    udpHeader.GetDestinationPort ());
                tupleValue ^= (udpHeader.GetSourcePort ()<<16);
                tupleValue ^= udpHeader.GetDestinationPort ();
                tupleValue ^= seqh.GetPG();
                // add random factors
                tupleValue /= (m_ipv4->GetObject<Node>()->GetId() + 1);
                break;
            }
        case TCP_PROT_NUMBER:
            {
                TcpHeader tcpHeader;
                ipPayload->PeekHeader (tcpHeader);
                NS_LOG_DEBUG ("Found TCP proto and header: " << 
                    tcpHeader.GetSourcePort () << ":" <<  
                    tcpHeader.GetDestinationPort ());
                tupleValue ^= (tcpHeader.GetSourcePort ()<<16);
                tupleValue ^= tcpHeader.GetDestinationPort ();
                // add random factors
                tupleValue /= (m_ipv4->GetObject<Node>()->GetId() + 1);
                break;
            }
        default:
            {
                NS_LOG_DEBUG ("Udp or Tcp header not found");
                break;
            }
    }
    return tupleValue;
}

    QbbNetDevice¶

    PointToPoint NetDevice in NS-3¶

    The ns-3 point-to-point model is of a very simple point to point data link connecting exactly two PointToPointNetDevice devices over an PointToPointChannel. This can be viewed as equivalent to a full duplex RS-232 or RS-422 link with null modem and no handshaking.

Data is encapsulated in the Point-to-Point Protocol (PPP – RFC 1661), however the Link Control Protocol (LCP) and associated state machine is not implemented. The PPP link is assumed to be established and authenticated at all times.

The PointToPointNetDevice provides following Attributes:

- Address: The ns3::Mac48Address of the device (if desired);
- DataRate: The data rate (ns3::DataRate) of the device;
- TxQueue: The transmit queue (ns3::Queue) used by the device;
- InterframeGap: The optional ns3::Time to wait between “frames”;
- Rx: A trace source for received packets;
- Drop: A trace source for dropped packets.

{
    ofstream orderfile;
    orderfile.open(order_filepath);
    vector<float> partioned_layer_paras;
    vector<int> indexs;
    int para_count = 0;
    for (auto &it : layer_paras)
    {
        para_sizes[para_count] = ceil(it * 1.0 / SERVER_NUM / 10);
        //std::cout << para_sizes[para_count] << " ";
        indexs.push_back(para_count++); // 0-LAYER_NUM vector
    }
    //std::cout << "\n";

    for (int i = 0; i < SERVER_NUM; i++)
        for (int j = 0; j < USED_PRIORITY_NUM - 1; j++)
            priority_thresholds[i][j] = 3 * (i + 1);
    for (int i = 0; i < SERVER_NUM; i++)
    {
        for (int j = 0; j < SERVER_NUM; j++)
        {
            unsigned seed = std::chrono::system_clock::now().time_since_epoch().count();
            shuffle(indexs.begin(), indexs.end(), std::default_random_engine(seed));    // shuffle index vector

            int k = 0;
            for (auto &it : indexs)
            {
                global_recv_send_index_order[i][j][k] = it;
                k++;
            }
            for (int kk = 0; kk < LARYER_NUM; kk++)
            {
                NS_LOG_INFO(""<< global_recv_send_index_order[i][j][kk] << " ");
            }
            NS_LOG_INFO("\n");

            recv_send_index_order[i][j][USED_HIGHEST_PRIORITY][0] = priority_thresholds[j][0] + 1;
            for (int prio_i = 1; prio_i < USED_PRIORITY_NUM - 1; prio_i++)
            {
                recv_send_index_order[i][j][USED_HIGHEST_PRIORITY - prio_i][0] = priority_thresholds[j][prio_i] - priority_thresholds[j][prio_i - 1];
            }
            recv_send_index_order[i][j][USED_HIGHEST_PRIORITY - USED_PRIORITY_NUM + 1][0] = LARYER_NUM - 
            priority_thresholds[j][USED_PRIORITY_NUM - 2] - 1;

            for (int prio_i = 0; prio_i < USED_PRIORITY_NUM; prio_i++)
            {
                uint32_t start_from = prio_i == 0 ? 0 : priority_thresholds[j][prio_i - 1] + 1;
                uint32_t end_to = prio_i == (USED_PRIORITY_NUM - 1) ? LARYER_NUM - 1 : priority_thresholds[j][prio_i];
                para_count = 1;
                for (int layer_i = 0; layer_i < LARYER_NUM; layer_i++)
                {
                    if (global_recv_send_index_order[i][j][layer_i] >= start_from && 
                        global_recv_send_index_order[i][j][layer_i] <= end_to)
                    {
                        recv_send_index_order[i][j][USED_HIGHEST_PRIORITY - prio_i][para_count++] =
